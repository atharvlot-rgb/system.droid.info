# system.droid.info
WACAT PC MONITOR — HOW TO RUN THE APP

Step 1: Open Command Prompt
Press Windows + R, type cmd, and press Enter.

Step 2: Go to the app folder
Copy and paste this command:
cd /d "C:\Users\atharvlot\OneDrive\Desktop"


Step 3: Install the required package
Run this command:
python -m pip install psutil


Step 4: Check the code
Run:
python -m py_compile wacat_pc_monitor.py


Step 5: Launch the app
Run:
python wacat_pc_monitor.py


Step 6: Enjoy Wacat PC Monitor!

You can use the app to monitor CPU usage, RAM usage, disk space, running processes, system information, and network troubleshooting tools.

Requirements:
- Windows 10 or later
- Python installed
- The psutil package
- The file wacat_pc_monitor.py
Troubleshooting: If the app does not start, check that the filename is correct and that Python is installed.
